## Abstract

Für den MQ-Point wurde ein Informationssystem entwickelt, das zur Ankündigung von tagesaktuellen Veranstaltungen im Museumsquartier dient und das Personal an den Schaltern entlasten soll. Die Installation besteht aus einem Server mit Datenbank, der einen Director Player mit den aktuellen Veranstaltungsdaten versorgt. Das System wird regelmäßig von realitylab gewartet. Technische Realisierung: Leo Peschta.
