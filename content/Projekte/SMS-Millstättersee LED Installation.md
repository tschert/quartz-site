## Abstract

Konzept für eine interaktive Medieninstallation am Millstätter See in Kärnten. Die Studie umfasste sowohl die Hardware, eine ortsspezifische LED-Installation, als auch die Software zur Steuerung der dafür entwickelten Inhalte.

## Content

> Concept development for an Interactive Media Installation at Millstättersee in Austria. The concept study included both Hardware development through a site specific LED installations as well as Software development to run the developed content.
